# 🚀 GUÍA RÁPIDA - Subir a GitHub Pages

## ⚡ Pasos súper rápidos (5 minutos)

### 1️⃣ Crear repositorio en GitHub
- Ve a https://github.com/new
- Nombre: `para-fati` (o el que quieras)
- Público ✅
- Create repository

### 2️⃣ Subir archivos
Arrastra estos archivos a GitHub:
```
✅ index.html
✅ styles.css
✅ script.js
✅ manifest.json
✅ sw.js
✅ icon.svg
```

**OPCIONAL pero recomendado:**
```
⭐ icon-192.png (usa icon-generator.html para crearlo)
⭐ icon-512.png (usa icon-generator.html para crearlo)
```

### 3️⃣ Activar GitHub Pages
1. Settings → Pages (menú izquierdo)
2. Source: **Deploy from a branch**
3. Branch: **main** + **/ (root)**
4. Save
5. ¡Espera 1-2 minutos!

### 4️⃣ ¡Listo!
Tu PWA estará en:
```
https://TU-USUARIO.github.io/para-fati/
```

## 📱 Compartir con Fati

### Link directo:
Envíale el link por WhatsApp, Instagram, etc.

### Mejor aún - Instalar como app:
1. Ella abre el link en su celular
2. En Android (Chrome): "Agregar a pantalla de inicio"
3. En iPhone (Safari): Botón compartir → "Agregar a pantalla de inicio"
4. ¡Ahora tiene una app "Para Fati ♡" en su teléfono! 💕

## 🎨 Generar los íconos PNG (opcional)

### Opción A - Automática:
1. Abre `icon-generator.html` en tu navegador
2. Clic en los botones para generar
3. Sube los archivos PNG a GitHub

### Opción B - Online:
1. Ve a https://cloudconvert.com/svg-to-png
2. Sube `icon.svg`
3. Genera en 192x192 y 512x512
4. Descarga y sube a GitHub

✅ **Prueba antes de compartir:** Abre el link en modo incógnito
✅ **Funciona offline:** Después de la primera carga

## ❓ Problemas comunes

**"No veo mi página"**
→ Espera 2-3 minutos, GitHub tarda en actualizar

**"Los estilos se ven mal"**
→ Ctrl+Shift+R (Cmd+Shift+R en Mac) para limpiar caché

**"No aparece el botón de instalar"**
→ Usa el menú del navegador → "Agregar a pantalla de inicio"

**"Quiero cambiar los colores/textos"**
→ Edita `styles.css` (colores) o `index.html` (textos)
